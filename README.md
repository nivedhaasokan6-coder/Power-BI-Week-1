# Power BI – Week 1 Data Preparation

## Overview

This project focuses on preparing and transforming the **Superstore Sales dataset** using **Microsoft Power BI Desktop**. The main purpose of this activity is to understand the Power BI interface, import a dataset, and perform basic data cleaning and transformation using **Power Query Editor**.

## Objectives

* To understand the basic Power BI Desktop interface.
* To import the Superstore Sales dataset.
* To examine the imported data in Power Query.
* To assign suitable data types to columns.
* To clean and standardize text-based fields.
* To create useful date-related fields such as Year, Quarter, Month, and Day.
* To prepare the dataset for further analysis and visualization.

## Tools Used

* **Power Query Editor**
* **CSV Dataset – Superstore Sales**

## Data Preparation Steps

1. Opened Power BI Desktop and started a new report.
2. Selected the required dataset for import.
3. Previewed the dataset before loading it.
4. Opened the data in Power Query Editor.
5. Reviewed the available columns and data types.
6. Changed the **Order Date** column to the appropriate Date type.
7. Applied locale settings for correct date interpretation.
8. Used text transformation options to clean categorical fields.
9. Standardized the **Category** and **Sub-Category** values.
10. Created additional date information such as Month.
11. Reviewed the Applied Steps to verify the transformations.

## Outcome

The Superstore Sales dataset was successfully imported and prepared in Power BI. Data types were configured correctly, text fields were cleaned, and date-related information was derived from the Order Date column. The prepared dataset can now be used for creating reports, charts, and further sales analysis.

## Conclusion

This Week 1 activity provided practical experience in using Power BI and Power Query for data preparation. The transformation process helped organize the dataset and improve its consistency, making it suitable for future visualization and analysis.
